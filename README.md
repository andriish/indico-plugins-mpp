# Indico Plugins (MPP)

This repository contains the MPP-specific plugins for [Indico][indico]. If you
are looking for the official plugins, see [indico-plugins][indico-plugins] and
[indico-plugins-cern][indico-plugins-cern].

| Plugin | Description |
| ------ | ----------- |
| [mpppanel](mpppanel/) | Per-room signage pages with the bookings of the day |
